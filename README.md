# Система управления арендой автомобилей

Информационная система для пункта проката: учёт автопарка, оформление договоров аренды, фиксация актов осмотра и предварительный расчёт стоимости до оплаты.

## Идея проекта

Система моделирует процесс проката автомобилей как набор связанных данных: классы автомобилей, автомобили, клиенты, договоры аренды и осмотры состояния. Проверка занятости автомобиля на период и запрет пересекающихся договоров выполняются на уровне базы данных.

Главная особенность системы: клиент видит полный расчёт стоимости до оплаты, включая лимит пробега, топливо и франшизу, а при возврате итог считается по тем же правилам и актам осмотра.
